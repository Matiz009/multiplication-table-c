# Multiplication Table (C)

A small C program that prints the multiplication table of any number, from 1 to 10.

## Features

- Reads a number (decimals allowed) from the user
- Prints its table from x1 to x10

## Tech stack

C

## Getting started

```bash
git clone https://github.com/Matiz009/multiplication-table-c.git
cd multiplication-table-c
gcc tablePrinter.c -o tablePrinter && ./tablePrinter
```

## Project structure

```
tablePrinter.c     Source code
tablePrinter.exe   Old Windows build
```
